{{- if eq .Values.database.type "postgresql" }}

PostgreSQL schema: SAJHA does not create tables. Before the pods can start, run the
schema file once against the database (then seed.sql, for the default roles and admin):
  kubectl -n {{ .Release.Namespace }} run sajha-sql --rm -i --restart=Never --image={{ include "sajha.image" . }} \
    --command -- python -m sajha.db sql --dialect postgresql > schema.sql
  kubectl -n {{ .Release.Namespace }} run sajha-sql --rm -i --restart=Never --image={{ include "sajha.image" . }} \
    --command -- python -m sajha.db sql --dialect postgresql --seed > seed.sql
  psql -v ON_ERROR_STOP=1 "<database URL>" -f schema.sql
  psql -v ON_ERROR_STOP=1 "<database URL>" -f seed.sql
Until then the pods log "Refusing to start: database schema is not ready" with the missing
tables (database.postgresql.schemaCheck: {{ .Values.database.postgresql.schemaCheck | default "strict" }}).
Guide: docs/getting-started/Database Setup.md
{{- end }}

  kubectl -n {{ .Release.Namespace }} exec deploy/{{ include "sajha.fullname" . }} -- python -c "import urllib.request; print(urllib.request.urlopen('http://127.0.0.1:3002/health').read()[:300])"
