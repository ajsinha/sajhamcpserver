Capabilities

Not a tool server. An intelligence server.

SAJHA embeds the LLM gateway, so it can reason about tools, resolve intent, compose workflows, and track costs. Other MCP servers are dumb pipes.

Embedded LLM Gateway

Anthropic, OpenAI, Bedrock, Together, Ollama, Azure — all via official SDKs. Registry factory for custom providers. DB-managed models with user-level overrides.

Semantic Tool Discovery

Describe what you need in English. Vector embeddings of {{ tool_count }} tool descriptions resolve intent to the right tool with confidence scores and auto-extracted parameters.

Composite Tools

Chain multiple tools into one call. Sibling pattern runs tools in parallel. Parent-Child fans out per record. Dynamic schemas built at boot from DB definitions.

OpenTelemetry Observability

Per-tool p50/p95/p99 latency histograms. Error spike alerting. Health probes for Kubernetes. Optional OTEL SDK exports to Datadog, Grafana, Splunk.

Multi-Tenancy

Tenant-isolated tool access with wildcard patterns. Per-tenant quotas, data isolation, and API key pools. Enterprise-ready from day one.

Plugin System

Drop a plugin directory with JSON tool configs or Python classes. Auto-discovered, checksum-verified, dependency-installed. Publish and share tool packs.

Multi-Layer Security

SAJHA JWTs, API keys and the session cookie, plus OAuth 2.1 on /mcp from the built-in authorization server or an external issuer. RBAC with wildcard tool permissions. Every call authenticated, authorised, and audit-logged.

MCP Studio

7 visual tool creators: Python, REST, DB Query, Script, PowerBI Report, PowerBI DAX, LiveLink. Analysts create tools without writing code. Hot-reload deploys in seconds.

Tool Versioning

Run v1 and v2 side-by-side. Deprecation lifecycle with sunset dates. Contract testing validates all {{ tool_count }} tools against live APIs. Zero surprises in production.

Connectivity

Streamable HTTP for every client. Legacy transports for the rest.

Every transport reaches the same MCPHandler: identical JSON-RPC 2.0, same auth, same audit logging.

POST /mcp

Streamable HTTP

Both eras: stateless 2026-07-28 requests and 2025-11-25 sessions. What every current MCP client uses.

GET /mcp/sse

HTTP+SSE (legacy)

The 2024-11-05 transport, with POST /mcp/message, for older clients that predate Streamable HTTP.

WS /mcp/ws

WebSocket (extension)

A SAJHA extension: full-duplex, with change notifications pushed. Authenticates with a SAJHA JWT or API key.
