How it works

                

                    
An LLM tool is an ordinary tool config whose implementation is sajha.ai.llm_tools.LLMTool and
                        which carries an llm block. This page writes that block; the inputs and outputs each mode needs are generated.

                    
    
                        
  • Runs as the caller: it may call only tools that both its allow list and the caller permit.
    • 
                        
  • Annotations are derived from the tools it may call, never trusted from the config.
    • 
                        
  • Limits are clamped to the server ceilings at every call.
    • 
                        
  • The check uses the loader's own rules, so what passes here loads.
    • 
                    

                    
Deploying needs the studio:llm permission (or studio:*). You may change or delete only the tools you created; an administrator may change any.
