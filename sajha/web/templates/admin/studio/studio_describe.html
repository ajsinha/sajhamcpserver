How it works

The model behind the {{ model_alias }} alias designs the tool (studio.describe.model; out of the box the offline mock-toolsmith). Its answer is checked like any untrusted input: names, URLs, SQL, headers and sandbox requests.

  • Python: model-written code, always sandboxed{% if sandbox %} (backend {{ sandbox.backend }}){% endif %}; it never runs in the server.
  • REST and database query: Studio's own generators, filled with checked values; no credentials are generated.
  • Composite: existing tools run together.
  • OpenAPI: handed to Import an API, where you pick the operations.

A deploy needs your approval of the exact version you reviewed, its tests run, and the policy engine's consent to studio.deploy.
