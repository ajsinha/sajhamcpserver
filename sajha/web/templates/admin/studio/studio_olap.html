What is an OLAP Dataset?
  • Semantic Layer: Business-friendly abstraction over raw database tables
  • Dimensions: Categories for grouping and filtering (e.g., Region, Date, Product)
  • Measures: Numeric values to aggregate (e.g., Revenue, Quantity, Profit)
  • Hierarchies: Drill-down paths (e.g., Year → Quarter → Month → Day)
