## Overview

The OECD tools (prefix `oecd_`, folder `config/tools/oecd/`) read the OECD Data Explorer: composite
leading indicators, key short-term economic indicators, quarterly national accounts and the Economic
Outlook projections as curated tools, any other OECD dataflow through `oecd_get_series`, and the
dataflow list through `oecd_search`. They cover the OECD members and the G20 in one source, monthly
and quarterly, where the World Bank (`wb_*`) is annual. Implementation: `sajha/tools/impl/oecd_tools.py`.
The live catalog in the app (Tools page, or `tools/list`) is authoritative.

## Data Source and Terms

- **API:** the OECD SDMX 2.1 REST API at `https://sdmx.oecd.org/public/rest/`, read as SDMX-CSV
  (`format=csvfile`). Flow references are `AGENCY,ID` (`OECD.SDD.STES,DSD_STES@DF_CLI`). No API key.
- **Shared client:** the tools are the `oecd` host profile of SAJHA's shared SDMX client
  (`sajha/tools/impl/sdmx_client.py`, registered with `register_host` in `oecd_tools.py`;
  [Tool Quality §12.3](../../architecture/Tool%20Quality.md#123-a-shared-sdmx-client)), so every
  fetch goes through the outbound fetch guard and the HTTP proxy, and only to the OECD host.
- **One shared hourly budget:** the OECD asks API users to stay at about 60 downloads an hour. Every
  request (data, and the dataflow list) first takes a slot in one sliding window kept in the state
  store (`opendata:oecd:requests`, 50 an hour), so every worker behind the organisation's egress IP
  shares the budget; when it is used up a call fails at once with a message saying so. Results are
  cached by each tool's `cache_ttl` (12 hours; the dataflow list a day), so ask for several countries
  in one call rather than one call each.
- **Terms:** OECD material published from July 2024 is licensed under CC BY 4.0
  ([open by default](https://www.oecd.org/en/about/oecd-open-by-default-policy.html)). Every result
  carries `source: "Source: OECD Data Explorer (sdmx.oecd.org), licensed under CC BY 4.0"`; quote it
  with the data.
- **Domain description:** `config/tools/oecd/domain.txt` (credit, budget, country codes, periods).

## Dataflows and Keys

| Tool | Dataflow | Key the tool builds | Unit |
|---|---|---|---|
| `oecd_leading_indicators` | `OECD.SDD.STES,DSD_STES@DF_CLI` | `{countries}.M.{LI, BCICP, CCICP}.IX._Z.AA.IX._Z.H` (amplitude adjusted) | Index, long-term average = 100 |
| `oecd_main_economic_indicators` | `OECD.SDD.STES,DSD_KEI@DF_KEI` | `{countries}.{M or Q}.{measures}.{units}.{activities}.{adjustments}.{transformations}`; series the `+` lists cross-match are dropped | Percent, percent a year, or index |
| `oecd_quarterly_national_accounts` | `OECD.SDD.NAD,DSD_NAMAIN1@DF_QNA` | `Q.Y.{countries}.{sector}.S1.{transaction}._Z.{activity}.{expenditure}.{unit}.{price base}.{transformation}.T0102` | Percent, or national currency (`unit_multiplier` millions) |
| `oecd_economic_outlook` | `OECD.ECO.MAD,DSD_EO@DF_EO` (the latest edition) | `{countries}.{measures}.A` | Percent, or percent of GDP |
| `oecd_get_series` | any | as given | as published |

The main economic indicators map to these DF_KEI series: `cpi_inflation` CP, growth over a year;
`unemployment_rate` UNEMP, seasonally adjusted; `long_term_rate` IRLT and `short_term_rate` IR3TIB,
percent a year; `industrial_production_growth` PRVM (industry excluding construction), growth over a
year; `leading_indicator` LI. The national accounts transactions are GDP (`B1GQ`), household and
government consumption (`P3` for sectors `S1M` and `S13`), gross fixed capital formation (`P51G`),
exports (`P6`) and imports (`P7`).

## Countries and Periods

- **Countries:** ISO 3166 alpha-3 (`USA`, `DEU`) on the wire; alpha-2 codes and names are converted.
  Aggregates are passed through: `OECD`, `G20`, `G7`, `EA20` (also `XM` and "euro area"),
  `EU27_2020`.
- **period:** `latest`; `last N months|quarters|years`; one period (`2025`, `2025-Q3`, `2025-07`); or
  a range `A/B`. Each tool's schema states its default.
- **Projections:** `oecd_economic_outlook` returns the latest edition's history and projections;
  observations from the current year on carry `projection: true`.

## Response Format

```json
{
  "dataflow": "OECD.SDD.STES,DSD_STES@DF_CLI",
  "key": "USA.M.LI.IX._Z.AA.IX._Z.H",
  "period": "2026-01/2026-03",
  "source": "Source: OECD Data Explorer (sdmx.oecd.org), licensed under CC BY 4.0",
  "series_count": 1,
  "series": [{
    "key": "USA.M.LI.IX._Z.AA.IX._Z.H", "country": "USA",
    "unit": "Index", "unit_code": "IX", "unit_multiplier": null, "base_period": null, "frequency": "Monthly",
    "dimensions": {"REF_AREA": "USA", "FREQ": "M", "MEASURE": "LI"},
    "observation_count": 3,
    "observations": [{"date": "2026-01", "value": 100.1517}]
  }]
}
```

Observations are oldest first. The curated indicator tools add `indicator` (the name asked for) to
each series. No data gives `series: []` and a `note`; more than `max_series` series gives
`truncated: true`.

## Calling the Tools

Every tool can be called over MCP (a `tools/call` request on `POST /mcp`) or over the REST API
(`POST /api/tools/execute`); see the [MCP Protocol Guide](../../protocol/MCP%20Protocol%20Guide.md)
and the [API Reference](../../protocol/API%20Reference.md).

```json
{"jsonrpc": "2.0", "id": 1, "method": "tools/call",
 "params": {"name": "oecd_main_economic_indicators",
            "arguments": {"countries": ["USA", "JPN", "GBR"], "indicators": ["cpi_inflation", "long_term_rate"]}}}
```

## Errors

| Situation | Result |
|---|---|
| Unknown country, unreadable period, or a dataflow id that is unknown or ambiguous | Argument error naming the value |
| The shared hourly budget is used up | Tool error (`OECD request budget ... is used up`) |
| No data for the selection (404 `NoRecordsFound`) | `series: []` with a `note` |
| OECD unreachable, refused by the outbound guard, or another HTTP error | Tool error (`OECD: ...`) |
