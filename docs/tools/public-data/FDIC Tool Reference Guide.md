# FDIC Tool Reference Guide

The FDIC tools (prefix `fdic_`, tool folder `config/tools/fdic/`, implementation
`sajha/tools/impl/fdic_tools.py`) read the FDIC's BankFind Suite: FDIC-insured institutions, their
quarterly Call Report figures, offices, structure history and branch deposits, and bank failures since
1934. The live catalog (`tools/list`, or the Tools page) is authoritative for the tools and their
parameters; the table below is generated from the tool configs.

Why these tools exist, and on what terms, is in
[Open Data Tools](../../architecture/Open%20Data%20Tools.md).

---

## Source and terms

The source is the BankFind API at `https://api.fdic.gov/banks/`, a US government work. It needs no
key today; its documentation says that may change. If it does, set the environment variable
`FDIC_API_KEY` and the tools send it as `api_key` (a 401 or 403 answer says so). Every result carries a
`source` field. Every request goes through the outbound fetch guard and HTTP proxy
(`sajha/core/outbound.py`).

## Rate limit and cache

BankFind answers `x-ratelimit-limit: 20` and does not document the window, and the whole organisation
shares one limit behind its egress IP. So:

- **Throttle.** Every request first takes a slot in one sliding window in the state store (20 requests a
  minute, key `opendata:fdic:requests`), shared by every worker when the state store is `redis` or
  `database` ([Scaling and State](../../architecture/Scaling%20and%20State.md)). A call waits up to 15
  seconds for a slot, then fails with a message saying the budget is used up.
- **Cache.** Each tool config sets `cache_ttl` (an hour), so a repeated call is answered from the tool
  result cache without a request.

## Conventions

- **Certificate number.** An institution is identified by its FDIC certificate number, `cert`. Find it
  with `fdic_institutions` (by fuzzy `name`, `state`, or `active`).
- **Units.** Dollar amounts are in **thousands** of US dollars, as BankFind reports them; ratios are in
  percent. Each result states its units. Income figures (`net_income`, `net_interest_income`) are year to
  date at the report date, as in the Call Report.
- **Dates** are `YYYY-MM-DD` (BankFind's own formats are converted). A **period** for
  `fdic_financials` is `2025`, `2025-Q3`, a range `2025-01-01:2025-12-31` or `last N quarters`
  (default `last 4 quarters`). Call Report data appear about two months after quarter end.
- **States** are two-letter US codes.
- **Limits.** List tools take a `limit`; `total` is BankFind's count and `truncated: true` says more
  rows exist.

### Financials

`fields` takes friendly names (`total_assets`, `total_deposits`, `domestic_deposits`, `net_loans`,
`equity`, `net_income`, `net_interest_income`, `noncurrent_loans`, `roa`, `roe`, `net_interest_margin`,
`efficiency_ratio`, `leverage_ratio`, `tier1_risk_based_ratio`, `total_risk_based_ratio`) or any BankFind
financial field code (for example `LNRE`, real estate loans), which is returned under its code.

### History

`fdic_history` lists institution-level events (mergers, charter, name and location changes, failures).
Large banks also have thousands of branch openings and closings; `include_branches: true` adds them.

### Summary of Deposits

`fdic_summary_of_deposits` gives deposits per branch as of 30 June of `year`, for one institution
(`cert`), every branch in a state (`state`), or both. The survey for a year is published in the autumn.

## Examples

```json
{"tool": "fdic_institutions", "arguments": {"name": "Silicon Valley Bank", "limit": 3}}
```

```json
{"tool": "fdic_financials", "arguments": {"cert": 628, "fields": ["total_assets", "net_income", "tier1_risk_based_ratio"], "period": "last 8 quarters"}}
```

## Testing

`tests/test_open_data_calendars_treasury_fdic.py` plays back responses recorded live
(`tests/fixtures/open_data/fdic_*.json`) and checks the throttle and the optional key, so the suite never
calls BankFind. The live tool check (`python -m sajha.quality check --folder fdic`) calls each tool once
with its example.
