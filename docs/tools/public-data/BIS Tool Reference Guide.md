## Overview

The BIS tools (prefix `bis_`, folder `config/tools/bis/`) read the cross-country statistics of the
Bank for International Settlements: central bank policy rates, credit-to-GDP gaps, total credit,
debt service ratios, property prices and effective exchange rates, plus any other BIS dataflow
through `bis_get_series`. They complement the single-central-bank folders (`ecb`,
`bank_of_canada`, `bank_of_japan`, `federal_reserve`, `peoples_bank_of_china`) with one source that
covers many countries in one call. Implementation: `sajha/tools/impl/bis_tools.py`. The live
catalog in the app (Tools page, or `tools/list`) is authoritative.

## Data Source and Terms

- **API:** the BIS SDMX 2.1 REST API at `https://stats.bis.org/api/v1/`, read as SDMX-CSV
  (`Accept: application/vnd.sdmx.data+csv;version=1.0.0`). No API key.
- **Shared client:** the tools are the `bis` host profile of SAJHA's shared SDMX client
  (`sajha/tools/impl/sdmx_client.py`, registered with `register_host` in `bis_tools.py`;
  [Tool Quality §12.3](../../architecture/Tool%20Quality.md#123-a-shared-sdmx-client)), so every
  fetch goes through the outbound fetch guard and the HTTP proxy, and only to the BIS host.
- **Terms:** the [Terms of permitted use of BIS statistics](https://data.bis.org/help/legal) ask
  that the BIS be cited. Every result carries `source: "Source: BIS (Bank for International
  Settlements, stats.bis.org)"`; quote it with the data (owner decision,
  [Open Data Tools §6](../../architecture/Open%20Data%20Tools.md#6-decisions)). The BIS may
  throttle by IP.
- **Domain description:** `config/tools/bis/domain.txt` (citation, country codes, period syntax).

## Datasets and Keys

| Tool | Dataflow | Key the tool builds | Unit |
|---|---|---|---|
| `bis_policy_rates` | `WS_CBPOL` | `{M or D}.{countries}` | Per cent per year |
| `bis_credit_gap` | `WS_CREDIT_GAP` | `Q.{countries}.P.A.C` (private non-financial sector, all lenders, gap) | Percentage points of GDP |
| `bis_total_credit` | `WS_TC` | `Q.{countries}.{sector}.A..{770, XDC or USD}.A` (all lenders, any valuation, break-adjusted) | Percentage of GDP, or currency (`unit_multiplier` billions) |
| `bis_debt_service_ratio` | `WS_DSR` | `Q.{countries}.{P, H or N}` | Per cent of income |
| `bis_property_prices` | `WS_SPP` (residential); `WS_CPP` (commercial) | `Q.{countries}.{R or N}.{628 or 771}`; `Q.{countries}.......` | Index, 2010 = 100, or year-on-year per cent |
| `bis_effective_exchange_rates` | `WS_EER` | `{M or D}.{R or N}.{B or N}.{countries}` | Index, 2020 = 100 |
| `bis_get_series` | any | as given | as published |

Sectors: `P` private non-financial, `H` households and NPISHs, `N` non-financial corporations,
`G` general government, `C` total non-financial. Government credit is published at both market and
nominal value, so `bis_total_credit` for `government` returns two series (`VALUATION` `M` and `N`).
Real effective exchange rates are monthly only; daily is nominal only. Detailed residential
property prices (`WS_DPP`: covered area, dwelling type, vintage) are reached through
`bis_get_series`. `WS_LONG_PP` is not a BIS dataflow.

## Countries and Periods

- **Countries:** ISO 3166 alpha-2 (`US`, `GB`), with BIS aggregates passed through (`XM` euro
  area, `5A` all reporting economies). ISO alpha-3 codes and country names (`Japan`, `euro area`)
  are converted. Several countries are joined into one request.
- **period:** `latest`; `last N days|weeks|months|quarters|years` (the period N months, quarters or
  years before the current one, so `last 12 months` starts at the same month a year ago); one period
  (`2025`, `2025-Q3`, `2025-07`, `2025-07-15`); or a range `A/B` or `A to B`. Each tool's schema
  states its default. Quarterly series typically end one to two quarters back.

## Response Format

```json
{
  "dataflow": "WS_CBPOL",
  "key": "M.US+GB",
  "period": "2026-08/2026-09",
  "source": "Source: BIS (Bank for International Settlements, stats.bis.org)",
  "series_count": 2,
  "series": [{
    "key": "M.US", "country": "US",
    "title": "Central bank policy rates - United States - Monthly - End of period",
    "unit": "Per cent per year", "unit_multiplier": null, "frequency": "Monthly",
    "dimensions": {"FREQ": "M", "REF_AREA": "US"},
    "observation_count": 2,
    "observations": [{"date": "2026-08", "value": 3.625}, {"date": "2026-09", "value": 3.875}]
  }]
}
```

Observations are oldest first. No data for a selection gives `series: []` and a `note`; more than
`max_series` series gives `truncated: true`.

## Calling the Tools

Every tool can be called over MCP (a `tools/call` request on `POST /mcp`) or over the REST API
(`POST /api/tools/execute`); see the [MCP Protocol Guide](../../protocol/MCP%20Protocol%20Guide.md)
and the [API Reference](../../protocol/API%20Reference.md).

```json
{"jsonrpc": "2.0", "id": 1, "method": "tools/call",
 "params": {"name": "bis_credit_gap", "arguments": {"countries": ["US", "CN"], "period": "last 5 years"}}}
```

## Errors

| Situation | Result |
|---|---|
| Unknown country or unreadable period | Argument error naming the value |
| No data for the selection (BIS 404 `NoRecordsFound`) | `series: []` with a `note` |
| Real effective exchange rate asked daily | Tool error |
| BIS unreachable, refused by the outbound guard, or another HTTP error | Tool error (`BIS: ...`) |
