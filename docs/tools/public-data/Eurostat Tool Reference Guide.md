## Overview

The Eurostat tools (prefix `eurostat_`, folder `config/tools/eurostat/`) read the statistical office
of the European Union: HICP inflation, quarterly GDP, unemployment, government debt and house prices
as curated tools, any other Eurostat dataset through `eurostat_get_series`, and the dataset catalogue
through `eurostat_search`. Eurostat is monthly and quarterly where the World Bank (`wb_*`) is annual,
and it covers every member state where the ECB (`ecb_*`) covers mostly the euro area.
Implementation: `sajha/tools/impl/eurostat_tools.py`. The live catalog in the app (Tools page, or
`tools/list`) is authoritative.

## Data Source and Terms

- **API:** Eurostat's SDMX 2.1 REST API at
  `https://ec.europa.eu/eurostat/api/dissemination/sdmx/2.1/`, read as SDMX-CSV (`format=SDMX-CSV`).
  `eurostat_search` reads the table of contents at `/catalogue/toc/txt` (cached for a day in each
  process). No API key.
- **Shared client:** the tools are the `eurostat` host profile of SAJHA's shared SDMX client
  (`sajha/tools/impl/sdmx_client.py`, registered with `register_host` in `eurostat_tools.py`;
  [Tool Quality §12.3](../../architecture/Tool%20Quality.md#123-a-shared-sdmx-client)), so every
  fetch goes through the outbound fetch guard and the HTTP proxy, and only to the Eurostat host. A
  dataset's dimension order comes from its data structure definition, cached for a day.
- **Terms:** the [Eurostat copyright notice](https://ec.europa.eu/eurostat/help/copyright-notice)
  allows reuse with acknowledgement (CC BY 4.0). Every result carries `source: "Source: Eurostat
  (ec.europa.eu/eurostat), reused under the Eurostat copyright notice (CC BY 4.0)"`; quote it with
  the data. Data that Eurostat marks as coming from other sources, which includes figures for
  countries outside the EU, EFTA and the candidate countries (for example the United States and
  Japan in `une_rt_m`), may not be reused commercially: a result that contains such a country also
  carries `reuse_note`.
- **Domain description:** `config/tools/eurostat/domain.txt` (credit, reuse rule, codes, periods).

## Datasets and Keys

| Tool | Dataset | Key the tool builds | Unit |
|---|---|---|---|
| `eurostat_hicp` | `prc_hicp_minr` | `M.{RCH_A, RCH_M or I25}.{item}.{countries}` | Percent, or index 2025 = 100 |
| `eurostat_gdp` | `namq_10_gdp` | `Q.{CLV_PCH_PRE, CLV_PCH_SM or CP_MEUR}.SCA.B1GQ.{countries}` | Percent (chain-linked volumes), or million euro |
| `eurostat_unemployment` | `une_rt_m` | `M.SA.{TOTAL, Y_LT25 or Y25-74}.PC_ACT.{T, M or F}.{countries}` | Percent of the labour force |
| `eurostat_government_debt` | `gov_10q_ggdebt` | `Q.GD.S13.{PC_GDP or MIO_EUR}.{countries}` | Percent of GDP, or million euro |
| `eurostat_house_prices` | `prc_hpi_q` | `Q.{TOTAL, DW_NEW or DW_EXST}.{RCH_A, RCH_Q or I15_Q}.{countries}` | Percent, or index 2015 = 100 |
| `eurostat_get_series` | any | built from `filters` in the dataset's dimension order; a dimension left out matches all | as published |

The HICP moved from `prc_hicp_manr` (frozen) to `prc_hicp_minr` (ECOICOP 2018, index 2025 = 100);
`item` is an ECOICOP 2018 code such as `TOTAL`, `CP01` (food) or `NRG` (energy). Eurostat checks
every code in a key against the dataset and refuses the whole query when one is not allowed; the
message names the code.

## Countries and Periods

- **Countries:** ISO 3166 alpha-2 or alpha-3 codes and names are converted to Eurostat's codes:
  Greece is `EL`, the United Kingdom `UK`, the euro area `EA21` (Bulgaria joined on 1 January 2026;
  `EA`, `XM` and "euro area" all mean `EA21`) and the European Union `EU27_2020`. Other Eurostat
  aggregates (`EA20`, `EU27_2020`) are passed through.
- **period:** `latest`; `last N months|quarters|years`; one period (`2025`, `2025-Q3`, `2025-07`); or
  a range `A/B`. Each tool's schema states its default.
- **Flags:** Eurostat flags observations (`p` provisional, `e` estimated, `b` break in series, ...);
  an observation carries its `flag`, and the result lists the flags present under `flags`.

## Response Format

```json
{
  "dataset": "prc_hicp_minr",
  "key": "M.RCH_A.TOTAL.DE+FR+EA21",
  "period": "2026-01/2026-06",
  "source": "Source: Eurostat (ec.europa.eu/eurostat), reused under the Eurostat copyright notice (CC BY 4.0)",
  "series_count": 3,
  "series": [{
    "key": "M.RCH_A.TOTAL.DE", "country": "DE",
    "unit": "Annual rate of change, percent", "unit_code": "RCH_A", "frequency": "Monthly",
    "last_update": "2026-10-02",
    "dimensions": {"freq": "M", "unit": "RCH_A", "coicop18": "TOTAL", "geo": "DE"},
    "observation_count": 6,
    "observations": [{"date": "2026-01", "value": 2.1}, {"date": "2026-02", "value": 2.0}]
  }]
}
```

Observations are oldest first. `last_update` is when Eurostat last updated the dataset. No data
gives `series: []` and a `note`; more than `max_series` series gives `truncated: true`.

## Calling the Tools

Every tool can be called over MCP (a `tools/call` request on `POST /mcp`) or over the REST API
(`POST /api/tools/execute`); see the [MCP Protocol Guide](../../protocol/MCP%20Protocol%20Guide.md)
and the [API Reference](../../protocol/API%20Reference.md).

```json
{"jsonrpc": "2.0", "id": 1, "method": "tools/call",
 "params": {"name": "eurostat_get_series",
            "arguments": {"dataset": "prc_hicp_minr",
                          "filters": {"freq": "M", "unit": "RCH_A", "coicop18": ["TOTAL", "NRG"], "geo": ["DE", "FR"]},
                          "period": "last 12 months"}}}
```

## Errors

| Situation | Result |
|---|---|
| Unknown country, dimension or unreadable period | Argument error naming the value |
| A code Eurostat does not allow in the dataset | Tool error with Eurostat's message (`INVALID_QUERY_DIMENSION_VALUE ...`) |
| No data for the selection | `series: []` with a `note` |
| Eurostat unreachable, refused by the outbound guard, or another HTTP error | Tool error (`Eurostat: ...`) |
