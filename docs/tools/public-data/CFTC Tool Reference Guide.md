## Overview

The CFTC tools (prefix `cftc_`, folder `config/tools/cftc/`) read the Commitments of Traders
(COT) reports of the US Commodity Futures Trading Commission: who holds the open interest in each
US futures market, week by week, by trader category. They find markets, return the newest report or
a history, and compute one category's net positioning as a percent of open interest. They complement
the commodity and futures tools in `openbb` and `fmp`. Implementation:
`sajha/tools/impl/cftc_tools.py`. The live catalog in the app (Tools page, or `tools/list`) is
authoritative.

---

## Data Source and Terms

- **API:** the CFTC's Socrata datasets at `https://publicreporting.cftc.gov/resource/<id>.json`,
  queried with SoQL (`$select`, `$where`, `$order`, `$limit`). Every query sorts newest first.
- **Key:** none. Without a Socrata app token, every caller behind the organisation's egress IP
  shares one anonymous pool, so an operator may set the environment variable `CFTC_APP_TOKEN`; the
  tools send it as `X-App-Token`. The live tool check calls the tools either way.
- **Terms:** the data is US government work in the public domain; the
  [CFTC web policy](https://www.cftc.gov/webpolicy/index.htm) asks that the CFTC be acknowledged.
  Every result carries `source: "Source: CFTC Commitments of Traders (publicreporting.cftc.gov)"`.
- **Rate limit and cache:** every request takes a slot in one sliding window kept in the state
  store (60 a minute, shared by every worker); results are cached for six hours (`cache_ttl`).
- **Outbound:** every fetch goes through the outbound fetch guard and HTTP proxy.
- **Domain description:** `config/tools/cftc/domain.txt`.

## Reports and Categories

| `report` | Dataset (`futures_only` / `combined`) | Categories |
|---|---|---|
| `legacy` | `6dca-aqww` / `jun7-fc8e` | `noncommercial`, `commercial`, `nonreportable` |
| `disaggregated` (physical commodities) | `72hh-3qpy` / `kh3c-gbw2` | `producer_merchant`, `swap_dealers`, `managed_money`, `other_reportables`, `nonreportable` |
| `tff` (traders in financial futures) | `gpe5-46if` / `yw9f-hn96` | `dealers`, `asset_managers`, `leveraged_funds`, `other_reportables`, `nonreportable` |

`kind` is `futures_only` (the default) or `combined` (futures and options, options delta-adjusted
by the CFTC). Each category has `long`, `short`, `spread` (where the report has one), `net`
(long minus short), the weekly changes, `pct_long` and `pct_short` (percent of open interest, as the
CFTC publishes them), the trader counts and `net_pct_of_open_interest` (computed). When no category
is given, `cftc_cot_net_positioning` uses the speculative category of the report: `noncommercial`,
`managed_money` or `leveraged_funds`.

## Markets and Periods

- **market:** a CFTC contract market code (`13874A` E-mini S&P 500, `088691` COMEX gold) or a
  name. A name is resolved among the markets reported most recently; when it matches more than one
  (for example `gold` matches gold and micro gold), the tool refuses and lists the codes, unless the
  name equals one market's name exactly. Find codes with `cftc_cot_markets`; by default it lists only
  markets reported in the last five weeks (`active_only`).
- **Dates:** reports are as of Tuesday and published on Friday. `from` and `to` are `YYYY-MM-DD`;
  `period` (net positioning) is `2025`, `2025-Q3`, `2025-07`, `last 12 months` or
  `YYYY-MM-DD:YYYY-MM-DD`.

## Response Format

```json
{
  "report": "tff", "report_name": "Traders in Financial Futures", "kind": "futures_only",
  "dataset": "gpe5-46if",
  "source": "Source: CFTC Commitments of Traders (publicreporting.cftc.gov)",
  "units": "positions in contracts; pct_* and net_pct_of_open_interest in percent of open interest",
  "report_date": "2026-10-06", "market": "E-MINI S&P 500 - CHICAGO MERCANTILE EXCHANGE",
  "code": "13874A", "open_interest": 1932227,
  "categories": {
    "leveraged_funds": {"long": 113223, "short": 528310, "spread": 48436, "net": -415087,
                        "net_pct_of_open_interest": -21.48, "pct_long": 5.9, "pct_short": 27.3}
  }
}
```

## Calling the Tools

Every tool can be called over MCP (a `tools/call` request on `POST /mcp`) or over the REST API
(`POST /api/tools/execute`); see the [MCP Protocol Guide](../../protocol/MCP%20Protocol%20Guide.md)
and the [API Reference](../../protocol/API%20Reference.md).

```json
{"jsonrpc": "2.0", "id": 1, "method": "tools/call",
 "params": {"name": "cftc_cot_net_positioning",
            "arguments": {"market": "088691", "report": "disaggregated", "category": "managed_money"}}}
```

## Errors

| Situation | Result |
|---|---|
| A market name that matches several current markets | Tool error listing the candidates and their codes |
| No market matches | Tool error pointing at `cftc_cot_markets` |
| A category the report does not have | Tool error naming the report's categories |
| The shared request budget is used up | Tool error ("request budget ... used up") |
| Socrata answers 429 | Tool error suggesting `CFTC_APP_TOKEN` |
