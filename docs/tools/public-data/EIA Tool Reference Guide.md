## Overview

The EIA tools (prefix `eia_`, folder `config/tools/eia/`) read the US Energy Information
Administration's Open Data API: oil spot prices and inventories, natural gas storage, retail
electricity, and the Short-Term Energy Outlook with its forecasts, plus any other EIA route through
`eia_browse` and `eia_series`. Implementation: `sajha/tools/impl/eia_tools.py`. The live catalog in
the app (Tools page, or `tools/list`) is authoritative.

---

## Data Source and Terms

- **API:** EIA Open Data API v2, `https://api.eia.gov/v2/`.
- **Key:** the environment variable `EIA_API_KEY` (free registration at
  `https://www.eia.gov/opendata/register.php`), sent as the `api_key` query parameter; the tool configs
  carry `"api_key": "${EIA_API_KEY:}"` and nothing goes in `config/application.yml`. Without it the
  tools use the public `DEMO_KEY`, which EIA accepts with a very small allowance for the whole
  organisation's IP (10 requests, then `Retry-After` of about a day, on 2026-10-12), and say so in
  `note`. The live tool check does not spend that allowance: it reports the EIA tools
  `not_configured` until `EIA_API_KEY` is set.
- **Limits:** about 9,000 requests an hour and 5 a second per key. Every request first takes slots in
  sliding windows in the state store (`opendata:eia:second` and `opendata:eia:hour` with a key,
  `opendata:eia:demo:day`, 10 a day, without), so all workers share them; results are cached for an hour (daily
  and weekly data) or six hours (`cache_ttl`).
- **Terms:** EIA data are US government works in the [public domain](https://www.eia.gov/about/copyrights_reuse.php).
  Every result carries `source` with the credit.
- **Outbound:** every request goes through the outbound fetch guard and the HTTP proxy
  (`sajha/core/outbound.py`).
- **Domain description:** `config/tools/eia/domain.txt`.

Every route and series id was checked against the live API on 2026-10-12. `eia_browse` walks the
tree (with `facet`, it lists a facet's values); `eia_series` reads any leaf route.

## Periods and Pages

- **period:** `2025`, `2025-Q3`, `2025-07`, `last N days|weeks|months|quarters|years`, or a date range
  `2025-01-01:2025-06-30`; it becomes EIA's `start` and `end` in the frequency's format (dates for daily
  and weekly, `YYYY-MM` for monthly). `eia_short_term_outlook` defaults to this month through the end
  of next year; later months are EIA forecasts (`note_forecast`).
- **Pages:** EIA returns at most 5,000 rows a request. The tools ask newest first and follow the
  pages (`offset`, `length`) until `max_rows`; the rows are returned oldest first, and `truncated` says
  when more matched.

## Response Format

```json
{
  "source": "Source: U.S. Energy Information Administration (EIA Open Data API, api.eia.gov)",
  "note": "No EIA_API_KEY is set: the shared api.data.gov DEMO_KEY was used, ...",
  "route": "petroleum/stoc/wstk", "frequency": "weekly", "period": "2026-09", "truncated": false,
  "series_count": 1,
  "series": [{
    "series_id": "WCESTUS1", "name": "crude_oil_excluding_spr",
    "label": "U.S. Ending Stocks excluding SPR of Crude Oil (Thousand Barrels)", "unit": "MBBL",
    "observation_count": 4,
    "observations": [{"date": "2026-09-04", "value": 424069.0}]
  }]
}
```

`eia_series` returns `rows` (EIA's own fields, data columns as numbers) instead of `series`.

## Calling the Tools

Every tool can be called over MCP (a `tools/call` request on `POST /mcp`) or over the REST API
(`POST /api/tools/execute`); see the [MCP Protocol Guide](../../protocol/MCP%20Protocol%20Guide.md)
and the [API Reference](../../protocol/API%20Reference.md).

```json
{"jsonrpc": "2.0", "id": 1, "method": "tools/call",
 "params": {"name": "eia_natural_gas_storage", "arguments": {"regions": ["lower_48"], "period": "last 3 months"}}}
```

## Errors

| Situation | Result |
|---|---|
| Rate limit (HTTP 429), or the shared budget used up | Tool error saying so (with the DEMO_KEY: set `EIA_API_KEY`) |
| EIA refuses the key | Tool error naming `EIA_API_KEY` |
| An unknown route, facet or frequency | Tool error with EIA's message |
| EIA unreachable or refused by the outbound guard | Tool error (`EIA ...`) |
