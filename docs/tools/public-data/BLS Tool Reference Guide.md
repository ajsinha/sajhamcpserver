## Overview

The BLS tools (prefix `bls_`, folder `config/tools/bls/`) read the US Bureau of Labor Statistics
directly: consumer and producer prices, payrolls, unemployment, the Employment Cost Index and job
openings, plus any BLS series by id through `bls_series`. The `fred_*` tools re-publish many of the
same series; these tools are the first-hand source. Implementation: `sajha/tools/impl/bls_tools.py`.
The live catalog in the app (Tools page, or `tools/list`) is authoritative.

## Data Source and Terms

- **API:** the BLS Public Data API, `https://api.bls.gov/publicAPI/v2/timeseries/data/` (with a key)
  or `/v1/` (keyless), called with a JSON `POST`.
- **Key:** the environment variable `BLS_API_KEY` (free registration at
  `https://data.bls.gov/registrationEngine/`); the tool configs carry `"api_key": "${BLS_API_KEY:}"`
  and nothing goes in `config/application.yml`. With the key the tools use v2 (500 queries a day,
  50 series and 20 years a query, series titles). Without it they use v1 (25 queries a day, 25
  series and 10 years a query) and say so in `api_version` and `note`; the live tool check still calls
  them (`keyless_fallback`).
- **Shared budget:** the daily limits are per IP address, so the whole organisation behind one egress
  IP shares them. Every query first takes a slot in a sliding window in the state store
  (`opendata:bls:v1:daily` or `opendata:bls:v2:daily`, and a burst window of 50 per 10 seconds), so all
  workers spend one budget; results are cached for six hours (`cache_ttl`).
- **Terms:** BLS data are public domain. The [BLS API terms of service](https://www.bls.gov/developers/termsOfService.htm)
  require the date the data were retrieved and the statement "BLS.gov cannot vouch for the data or
  analyses derived from these data after the data have been retrieved from BLS.gov." Every result
  carries `source`, `retrieved` and `disclaimer`; quote them with the data.
- **Outbound:** every request goes through the outbound fetch guard and the HTTP proxy
  (`sajha/core/outbound.py`).
- **Domain description:** `config/tools/bls/domain.txt`.

## Periods and Derived Changes

- **period** (curated tools): `2025`, `2025-Q3`, `2025-07`, `last N days|weeks|months|quarters|years`,
  or a date range `2024-01-01:2025-06-30`. A period is kept when it overlaps the range.
- **from_year / to_year** (`bls_series`): whole years, at most 10 (v1) or 20 (v2).
- **Dates:** monthly `YYYY-MM`, quarterly `YYYY-Qn`, semiannual `YYYY-Sn`, annual `YYYY`. BLS annual
  averages (`M13`, `Q05`, `S03`) are left out.
- **Derived:** price and wage indexes carry `change_12m_percent` (against the same period a year
  earlier, so the tool asks BLS for one extra year); levels (payrolls, JOLTS counts) carry `change`
  from the previous period; rates are as published. `preliminary` is BLS's `P` footnote.

## Response Format

```json
{
  "source": "Source: U.S. Bureau of Labor Statistics (BLS Public Data API, api.bls.gov)",
  "disclaimer": "BLS.gov cannot vouch for the data or analyses derived from these data after the data have been retrieved from BLS.gov.",
  "retrieved": "2026-10-12",
  "api_version": "v1 (keyless)",
  "note": "No BLS_API_KEY is set: ...",
  "period": "2025-01-01:2025-12-31",
  "series_count": 1,
  "series": [{
    "measure": "total_nonfarm", "series_id": "CES0000000001", "label": "Total nonfarm employment",
    "unit": "thousands of jobs", "seasonally_adjusted": true, "frequency": "Monthly",
    "observation_count": 12,
    "observations": [{"date": "2025-01", "value": 158268.0, "preliminary": false, "change": -48.0}]
  }],
  "messages": []
}
```

Observations are oldest first. `messages` passes on what BLS reports (an unknown series id, for
example).

## Calling the Tools

Every tool can be called over MCP (a `tools/call` request on `POST /mcp`) or over the REST API
(`POST /api/tools/execute`); see the [MCP Protocol Guide](../../protocol/MCP%20Protocol%20Guide.md)
and the [API Reference](../../protocol/API%20Reference.md).

```json
{"jsonrpc": "2.0", "id": 1, "method": "tools/call",
 "params": {"name": "bls_cpi", "arguments": {"measures": ["all_items", "core"], "period": "last 12 months"}}}
```

## Errors

| Situation | Result |
|---|---|
| More years or series than the tier allows | Argument error naming the limit |
| The shared daily budget is used up | Tool error (`... request budget ... is used up`) |
| BLS reports its daily threshold reached | Tool error (`BLS daily rate limit reached: ...`) |
| An unknown series id | The series comes back without observations and `messages` says why |
| BLS unreachable, refused by the outbound guard, or another HTTP error | Tool error (`BLS ...`) |
