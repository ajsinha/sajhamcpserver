## Overview

The IMF tools (prefix `imf_`) read International Monetary Fund statistics: the World Economic Outlook, consumer prices, exchange rates, interest rates, international reserves, money, balance of payments, commodity prices and every other dataflow the IMF publishes. Implementation: `sajha/tools/impl/imf_tool_refactored.py`. The live catalog in the app (Tools page, or `tools/list`) is authoritative.

The IMF retired its legacy SDMX JSON service (`dataservices.imf.org`) and its International Financial Statistics (IFS) database. Since 8.8.0 the tools read the IMF's current SDMX 2.1 API (`api.imf.org/external/sdmx/2.1`, checked live: no key and no subscription needed) through SAJHA's shared SDMX client (`sajha/tools/impl/sdmx_client.py`; [Tool Quality §12.3](../../architecture/Tool%20Quality.md#123-a-shared-sdmx-client)). Former IFS indicators come from their successor dataflows: `CPI`, `ER` (exchange rates), `MFS_IR` (interest rates), `IL` (international liquidity) and `MFS_MA` (monetary aggregates).

---

## Data Source and Keys

No API key. Fetches go through the outbound fetch guard and the HTTP proxy (`tools.outbound.*`, see the [Configuration Reference](../../getting-started/Configuration%20Reference.md)) and only to the IMF host. Structure metadata (the dataflow list, a dataflow's dimensions and codes) is cached per process for an hour. The IMF's terms ask that the IMF be cited; every result carries a `source`.

## Curated Indicators

**WEO (`imf_get_weo_data`, `imf_compare_countries`)**: `gdp_growth` (NGDP_RPCH, real, %), `gdp_usd` (NGDPD, current US dollars), `gdp_per_capita` (NGDPDPC, US dollars), `inflation_avg` (PCPIPCH), `inflation_eop` (PCPIEPCH), `unemployment` (LUR, %), `current_account` (BCA_NGDPD), `fiscal_balance` (GGXCNL_NGDP), `public_debt` (GGXWDG_NGDP), all three % of GDP; `exports_volume` (TXG_RPCH), `imports_volume` (TMG_RPCH), % change; `population` (LP, persons). Any other WEO code works as `indicator_code` (`imf_get_dataflows` with database WEO and dimension INDICATOR lists them). Values after a series' `latest_actual_year` are projections.

**Former IFS (`imf_get_ifs_data`, `imf_compare_countries` with database IFS)**:

| Indicator | Dataflow / key (`{c}` country, `{f}` frequency) | Unit |
|-----------|-----------------------------------------------|------|
| `exchange_rate`, `exchange_rate_avg` | `ER` / `{c}.XDC_USD.EOP_RT.{f}`, `{c}.XDC_USD.PA_RT.{f}` | national currency per US dollar, end of period / period average |
| `policy_rate` | `MFS_IR` / `{c}.MFS166_RT_PT_A_PT.{f}` | % a year |
| `treasury_bill_yield`, `deposit_rate`, `lending_rate`, `money_market_rate` | `MFS_IR` / `GSTBILY_RT_PT_A_PT`, `MFS135_RT_PT_A_PT`, `MFS162_RT_PT_A_PT`, `MMRT_RT_PT_A_PT` | % a year |
| `cpi`, `cpi_inflation` | `CPI` / `{c}.CPI._T.IX.{f}`, `{c}.CPI._T.YOY_PCH_PA_PT.{f}` | index; % on a year earlier |
| `international_reserves` | `IL` / `{c}.TRGMV_REVS.USD.{f}` | US dollars, gold at market value |
| `broad_money` | `MFS_MA` / `{c}.BM_MAI.XDC.{f}` | national currency |

Coverage varies by country: several large economies (the United Kingdom, India, China among them) report no `MFS_IR` or `MFS_MA` data, so those indicators return a `note` instead of observations. The IFS indicators that have no successor series (core CPI, PPI, M1-M3, reserve money, gold and foreign-exchange reserves separately, GDP, industrial production, trade, unemployment) are no longer offered; use WEO, `imf_get_data` or the World Bank tools.

**BOP (`imf_get_bop_data`)**: `current_account` (NETCD_T.CAB), `goods_and_services` (NETCD_T.GS), `capital_account` (NETCD_T.KAB), `financial_account` (NNAFANIL_T.FAB), `current_account_credit` (CD_T.TCDCA), `current_account_debit` (DB_T.TDBCA); key `{c}.<code>.USD.{A|Q}`.

## Keys, Countries and Periods

- **Countries** are ISO alpha-3 on the wire (`USA`); alpha-2 (`US`) is converted (`sajha/tools/impl/country_codes.py`). IMF group codes (`G001` world, WEO region codes) pass through unchanged.
- **Keys** join one code per dimension with dots. `+` selects several codes (`USA+DEU.NGDP_RPCH.A`), and an empty position takes every code. `imf_get_dataflows` shows the order: WEO is `COUNTRY.INDICATOR.FREQUENCY`, CPI is `COUNTRY.INDEX_TYPE.COICOP_1999.TYPE_OF_TRANSFORMATION.FREQUENCY`, PCPS (commodity prices) is `COUNTRY.INDICATOR.DATA_TRANSFORMATION.FREQUENCY`, so the gold price is `imf_get_data` with database `PCPS` and key `G001.PGOLD.USD.M`.
- **Periods**: `start_year` and `end_year` bound the request; with neither, the whole history is returned. Monthly periods are reported as `YYYY-MM`, quarterly as `YYYY-Qn`.

## Response Format

Single-series tools (`imf_get_weo_data`, `imf_get_ifs_data`, `imf_get_bop_data`):

```json
{
  "database": "WEO",
  "key": "USA.NGDP_RPCH.A",
  "country_code": "USA",
  "indicator_code": "NGDP_RPCH",
  "frequency": "A",
  "name": "Gross domestic product (GDP), Constant prices, Percent change",
  "data": [{"period": "2024", "value": 2.793116}, {"period": "2025", "value": 2.11733}],
  "count": 2,
  "source": "Source: IMF data portal (api.imf.org SDMX 2.1)",
  "latest_actual_year": "2025"
}
```

`imf_get_data` returns `series` (each with `key`, `dimensions`, `name`, `data`); `imf_compare_countries` returns `countries`. A series with no observations gives a `note`; an IMF error is a tool error.

## Calling the Tools

Every tool can be called over MCP (a `tools/call` request on `POST /mcp`) or over the REST API (`POST /api/tools/execute`). Authenticate with an `X-API-Key: sja_...` header or an `Authorization: Bearer <token>` header. Sessions, protocol versions and headers are covered in the [MCP Protocol Guide](../../protocol/MCP%20Protocol%20Guide.md).

**MCP (`POST /mcp`)**

```json
{"jsonrpc": "2.0", "id": 1, "method": "tools/call",
 "params": {"name": "imf_get_weo_data", "arguments": {"country_code": "US", "indicator": "gdp_growth", "start_year": 2020, "end_year": 2024}}}
```

**REST**

```bash
curl -X POST http://localhost:3002/api/tools/execute \
  -H "X-API-Key: sja_your_key" -H "Content-Type: application/json" \
  -d '{"tool": "imf_get_weo_data", "arguments": {"country_code": "US", "indicator": "gdp_growth", "start_year": 2020, "end_year": 2024}}'
```

**Python client SDK**

```python
from sajhaclient import SajhaClient, SajhaConfig

client = SajhaClient(SajhaConfig(base_url="http://localhost:3002", api_key="sja_your_key"))
result = client.execute_tool("imf_get_weo_data", country_code="US", indicator="gdp_growth", start_year=2020, end_year=2024)
```

## Troubleshooting

| Symptom | Cause / fix |
|---------|-------------|
| `... keys have the dimensions ...; pass the full key` | That dataflow is not keyed `COUNTRY.INDICATOR.FREQUENCY`; build the key from `imf_get_dataflows`. |
| `IMF data portal: imf: HTTP 403` | The dataflow id or agency is wrong (WEO, PCPS and CTOT belong to IMF.RES and are addressed so automatically; others to IMF.STA). |
| A `note` and no data | The country does not report that series, or not for that period. |
