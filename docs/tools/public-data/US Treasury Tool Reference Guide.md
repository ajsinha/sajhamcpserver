# US Treasury Tool Reference Guide

The US Treasury tools (prefix `ust_`, tool folder `config/tools/us_treasury/`, implementation
`sajha/tools/impl/us_treasury_tools.py`) read the official US Treasury yield curve, public debt,
average interest rates, auction results, the Daily Treasury Statement and the Treasury reporting rates
of exchange. The live catalog (`tools/list`, or the Tools page) is authoritative for the tools and their
parameters; the table below is generated from the tool configs.

Why these tools exist, and on what terms, is in
[Open Data Tools](../../architecture/Open%20Data%20Tools.md).

---

## Sources and terms

| Source | Used by | Key | Terms |
|---|---|---|---|
| Fiscal Data API, `https://api.fiscaldata.treasury.gov/services/api/fiscal_service/` | every tool except `ust_yield_curve` | none | "free, without restriction" (US government work) |
| Daily Treasury Rates, `https://home.treasury.gov/resource-center/data-chart-center/interest-rates/` (CSV, one file per year) | `ust_yield_curve` | none | US government work |

Every result carries a `source` field naming the Treasury source. Every request goes through the
outbound fetch guard and HTTP proxy (`sajha/core/outbound.py`), so `tools.outbound.proxy` applies.
Neither source publishes a rate limit.

## Conventions

- **Dates** are `YYYY-MM-DD`. A **period** is `2025`, `2025-Q3`, `2025-07`, a range
  `2025-01-01:2025-06-30`, or `last N days|weeks|months|quarters|years`.
- **No date means the latest**: the latest curve, the latest debt figure, the latest month of average
  rates, the latest statement, the latest quarter of exchange rates.
- **Units** are stated in each result's `units` field: rates and yields in percent; debt and auction
  amounts in US dollars; Daily Treasury Statement amounts in **millions** of US dollars; exchange rates
  in foreign currency units per US dollar.
- **Order**: time series oldest first; auctions newest first.
- **Truncation**: Fiscal Data pages are read up to 10,000 rows; `truncated: true` says rows were left
  out (narrow the dates).

### Yield curve

`curve` is `nominal` (par yields, 1M to 30Y, including the 1.5-month bill), `real` (TIPS par real
yields, 5Y to 30Y) or `bills` (4W to 52W). Bill rates come as two numbers per tenor: `yields` holds the
coupon-equivalent rate and `bank_discount` the bank discount rate. Tenor names are `1M`, `1.5M`, `3M`,
`2Y`, `10Y` and so on (`4W` to `52W` for bills); `tenors` keeps only the ones named. A `date` on a
weekend or holiday returns the last curve before it. A range spans at most ten calendar years (one file
per year is fetched).

### Auctions

`security_type` is `Bill`, `Note`, `Bond`, `TIPS` or `FRN`. Notes and bonds exclude TIPS and FRNs, which
have their own types. `term` matches the **original** term (`10-Year`), so reopenings (whose remaining
term reads `9-Year 10-Month`) are included; bills match their own term (`13-Week`). An auction that has
been announced but not held has `results_published: false` and null results. The upcoming-auctions
dataset is not used: announced auctions already appear here.

### Daily Treasury Statement

`table` is one of the current DTS tables: `operating_cash_balance` (the Treasury General Account),
`deposits_withdrawals_operating_cash`, `public_debt_transactions`,
`adjustment_public_debt_transactions_cash_basis`, `debt_subject_to_limit`,
`inter_agency_tax_transfers` and `income_tax_refunds_issued`. Each row keeps the table's own columns;
columns ending `_amt` or `_bal` are numbers. Two older tables (federal tax deposits and short-term cash
investments) stopped in 2023 and are not offered.

### Exchange rates

These are the Treasury's **reporting** rates, set quarterly for government accounting, not market rates
(use the central bank tools for those). Give `country` (an ISO 3166 code such as `CA`, `EA` for the euro
area, or the Treasury's name such as `Canada`) or `currency` (an ISO 4217 code for the common currencies,
such as `EUR` or `JPY`, or the Treasury's currency name such as `Euro`). Euro area members are listed
under the euro area, not by country.

## Examples

```json
{"tool": "ust_yield_curve", "arguments": {"curve": "nominal", "tenors": ["2Y", "10Y", "30Y"]}}
```

```json
{"tool": "ust_auctions", "arguments": {"security_type": "Note", "term": "10-Year", "limit": 5}}
```

## Testing

`tests/test_open_data_calendars_treasury_fdic.py` plays back responses recorded live
(`tests/fixtures/open_data/ust_*.json`), so the suite never calls the Treasury. The live tool check
(`python -m sajha.quality check --folder us_treasury`) calls each tool once with its example.
