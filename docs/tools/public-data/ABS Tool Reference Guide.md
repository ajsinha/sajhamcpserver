## Overview

The ABS tools (Australian Bureau of Statistics; prefix `abs_`, folder `config/tools/abs/`) read Australia's national statistical
office: the consumer price index, the Labour Force survey and the national accounts key aggregates
as curated tools, and any other ABS dataflow through `abs_get_series`. Implementation:
`sajha/tools/impl/abs_tools.py`. The live catalog in the app (Tools page, or `tools/list`) is
authoritative.

---

## Data Source and Terms

- **API:** the ABS Data API, SDMX 2.1 REST at `https://data.api.abs.gov.au/rest/`, read as SDMX-CSV
  (`Accept: application/vnd.sdmx.data+csv;version=1.0.0`). Flow references are `ABS,<ID>`. No API key
  (keys were removed in 2024).
- **Shared client:** the tools are the `abs` host profile of SAJHA's shared SDMX client
  (`sajha/tools/impl/sdmx_client.py`, registered with `register_host` in `abs_tools.py`;
  [Tool Quality §12.3](../../architecture/Tool%20Quality.md#123-a-shared-sdmx-client)), so every
  fetch goes through the outbound fetch guard and the HTTP proxy, and only to the ABS host.
- **Limits:** a response may take at most 30 seconds and 10 MB, so the curated tools ask for one
  fully specified key; keep `abs_get_series` keys narrow too.
- **Terms:** ABS material is licensed under CC BY 4.0
  ([copyright](https://www.abs.gov.au/website-privacy-copyright-and-disclaimer)). Every result
  carries `source: "Source: Australian Bureau of Statistics (data.api.abs.gov.au), licensed under
  CC BY 4.0"`; quote it with the data.
- **Domain description:** `config/tools/abs/domain.txt` (credit, regions, adjustment, periods).

## Dataflows and Keys

| Tool | Dataflow | Key the tool builds | Unit |
|---|---|---|---|
| `abs_cpi` | `ABS,CPI` | `{1, 2 or 3}.{item}.{adjustment}.{regions}.{M or Q}` | Index, or percent |
| `abs_labour_force` | `ABS,LF` | `{measures}.{sex}.1599.{adjustment}.{region}.M` (ages 15 and over) | Percent, or thousands of persons |
| `abs_gdp` | `ABS,ANA_AGG` | `{measures}.{item}.{adjustment}.AUS.Q` | Percent, or million AUD |
| `abs_get_series` | any | as given | as published |

CPI measures: `1` index, `2` change from the previous period, `3` change from the same period a year
earlier. The ABS publishes a complete monthly CPI from late 2025; the quarterly series continue.
`item` is a CPI `INDEX` code (`10001` all groups, `20001` food and non-alcoholic beverages). Labour
Force measures: `M13` unemployment rate, `M3` employed, `M6` unemployed, `M12` participation rate,
`M16` employment to population ratio, `M23` underemployment rate, `M24` underutilisation rate, `M9`
labour force. National accounts measures: `M1` chain volume, `M2` its change, `M3` current prices,
`M4` their change.

## Regions, Adjustment and Periods

- **Regions:** the CPI covers Australia (the weighted average of the eight capital cities) and the
  capital cities by name (`sydney`, `melbourne`, ...); the Labour Force covers Australia and the
  states and territories (`nsw`, `vic`, `qld`, `sa`, `wa`, `tas`, `nt`, `act`).
- **Adjustment:** `original`, `seasonally_adjusted` or `trend` (the ABS `TSEST` dimension).
- **period:** `latest`; `last N months|quarters|years`; one period (`2025`, `2025-Q3`, `2025-07`); or
  a range `A/B`. Each tool's schema states its default.

## Response Format

```json
{
  "dataflow": "ABS,LF",
  "key": "M13+M3.3.1599.20.AUS.M",
  "period": "2026-01/2026-06",
  "source": "Source: Australian Bureau of Statistics (data.api.abs.gov.au), licensed under CC BY 4.0",
  "series_count": 2,
  "series": [{
    "key": "M13.3.1599.20.AUS.M", "region": "AUS", "measure": "unemployment_rate",
    "unit": "Percent", "unit_multiplier": null, "adjustment": "seasonally_adjusted", "frequency": "Monthly",
    "dimensions": {"MEASURE": "M13", "SEX": "3", "AGE": "1599", "TSEST": "20", "REGION": "AUS", "FREQ": "M"},
    "observation_count": 6,
    "observations": [{"date": "2026-01", "value": 4.08312439}]
  }]
}
```

Observations are oldest first. Counts carry `unit_multiplier` (`thousands` for persons, `millions`
for dollars). No data (404 `NoRecordsFound`) gives `series: []` and a `note`.

## Calling the Tools

Every tool can be called over MCP (a `tools/call` request on `POST /mcp`) or over the REST API
(`POST /api/tools/execute`); see the [MCP Protocol Guide](../../protocol/MCP%20Protocol%20Guide.md)
and the [API Reference](../../protocol/API%20Reference.md).

```json
{"jsonrpc": "2.0", "id": 1, "method": "tools/call",
 "params": {"name": "abs_cpi", "arguments": {"measure": "annual_change", "regions": ["australia", "sydney"]}}}
```

## Errors

| Situation | Result |
|---|---|
| Unknown region or unreadable period | Argument error naming the value |
| No data for the selection (404 `NoRecordsFound`) | `series: []` with a `note` |
| ABS unreachable, refused by the outbound guard, or another HTTP error | Tool error (`ABS: ...`) |
