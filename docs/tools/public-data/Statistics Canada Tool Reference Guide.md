## Overview

The Statistics Canada tools (prefix `statcan_`, folder `config/tools/statcan/`) read the tables and
series of Statistics Canada's Web Data Service: prices, the labour force, national accounts and the
rest of the national statistics. They find tables, list a table's dimensions, return one series by
vector or by coordinate, and list the tables released on a day. They complement the
`bank_of_canada` tools. Implementation: `sajha/tools/impl/statcan_tools.py`. The live catalog in
the app (Tools page, or `tools/list`) is authoritative.

## Data Source and Terms

- **API:** the Web Data Service (WDS) at `https://www150.statcan.gc.ca/t1/wds/rest/`
  ([user guide](https://www.statcan.gc.ca/en/developers/wds/user-guide)). No key.
- **Terms:** the [Statistics Canada Open Licence](https://www.statcan.gc.ca/en/terms-conditions/open-licence)
  allows commercial use with the notice "Source: Statistics Canada, name of product, reference date.
  Reproduced and distributed on an "as is" basis with the permission of Statistics Canada." Every
  series result carries that notice in `source`, built from the table number and title and the
  newest reference period returned; quote it with the data.
- **Rate limit and cache:** WDS allows 25 requests per second per IP. Every request takes a slot in
  one window kept in the state store (20 a second, shared by every worker). The table list (about
  5 MB) and the code sets are cached per process for six hours, each table's metadata for an hour,
  and results by `cache_ttl`.
- **Outbound:** every fetch goes through the outbound fetch guard and HTTP proxy.
- **Domain description:** `config/tools/statcan/domain.txt`.

## Tables, Vectors and Coordinates

- **table:** a table number such as `18-10-0004-01` (also accepted: `18-10-0004`, `1810000401`,
  the product id `18100004`). Find tables with `statcan_search_tables` (every word must be in the
  title; current tables first, archived ones only with `include_archived`).
- **vector:** a series id such as `v41690973` (all-items CPI, Canada).
- **coordinate:** one member id per dimension, in the table's dimension order, joined by dots
  (`2.2` is Canada, All-items in table 18-10-0004-01); it is padded with zeros to ten positions.
  `statcan_table` without a coordinate lists the dimensions and their members with ids.
- **latest_n or period:** the newest N periods (default 12), or a period (`2025`, `2025-Q3`,
  `2025-07`, `last 2 years`, `YYYY-MM-DD:YYYY-MM-DD`); not both.
- **Dates:** monthly `YYYY-MM`, quarterly `YYYY-Qn`, annual `YYYY`, daily `YYYY-MM-DD`.
- **Units:** `unit` (for example `Dollars`, `2002=100`, `Percent`) and `unit_multiplier`
  (`thousands`, `millions`, or null). An observation flagged by Statistics Canada carries
  `symbol` (`preliminary`, `revised`).
- **statcan_changed_series:** the tables released on a date (WDS `getChangedCubeList`); every series
  of a listed table may have changed. `with_titles` adds titles from the table list.

## Calling the Tools

Every tool can be called over MCP (a `tools/call` request on `POST /mcp`) or over the REST API
(`POST /api/tools/execute`); see the [MCP Protocol Guide](../../protocol/MCP%20Protocol%20Guide.md)
and the [API Reference](../../protocol/API%20Reference.md).

```json
{"jsonrpc": "2.0", "id": 1, "method": "tools/call",
 "params": {"name": "statcan_table", "arguments": {"table": "14-10-0287-01"}}}
```

## Errors

| Situation | Result |
|---|---|
| Unreadable table, vector or coordinate | Tool error naming the value |
| Both `latest_n` and `period` | Tool error |
| WDS answers `FAILED` (no such table, vector or coordinate) | Tool error with Statistics Canada's message |
| The day's list is not released yet (HTTP 409) | Tool error ("not released yet") |
| The shared request budget is used up | Tool error ("request budget ... used up") |
