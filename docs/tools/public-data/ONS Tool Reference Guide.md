## Overview

The ONS tools (prefix `ons_`, folder `config/tools/ons/`) read the time series of the UK Office for
National Statistics: inflation, GDP, the labour market and every other series the ONS publishes
with a CDID. `ons_search` finds series; `ons_timeseries` returns one. Implementation:
`sajha/tools/impl/ons_tools.py`. The live catalog in the app (Tools page, or `tools/list`) is
authoritative.

---

## Data Source and Terms

- **APIs:** the search API at `https://api.beta.ons.gov.uk/v1/search` (with
  `content_type=timeseries`) finds a series and its page; the website's time-series JSON
  (`https://www.ons.gov.uk/<series page>/data`) returns the whole series. That second path is not
  documented as an API ([Open Data Tools §2](../../architecture/Open%20Data%20Tools.md#2-verdicts)
  caveat); the tools take the page from the search API rather than building it, so a moved series
  still resolves. No key.
- **Terms:** [Open Government Licence v3.0](https://www.nationalarchives.gov.uk/doc/open-government-licence/version/3/)
  ([ONS terms](https://www.ons.gov.uk/help/termsandconditions)). Every result carries
  `source: "Source: Office for National Statistics licensed under the Open Government Licence v3.0 (ons.gov.uk)"`.
- **Rate limit and cache:** ONS allows bots 120 requests per 10 seconds and 200 per minute
  ([guidance](https://developer.ons.gov.uk/bots/)). Every request takes a slot in two windows kept in
  the state store (100 per 10 seconds and 180 per minute, shared by every worker); results are cached
  (`cache_ttl`: a day for search, six hours for series).
- **Outbound:** every fetch goes through the outbound fetch guard and HTTP proxy.
- **Domain description:** `config/tools/ons/domain.txt`.

## Series and Periods

- **cdid:** the four-character series id (`D7G7` CPI annual rate, `L55O` CPIH annual rate, `ABMI`
  real GDP, `MGSX` unemployment rate). A CDID can be published in several datasets (`ABMI` is in
  `QNA`, `UKEA`, `PN2` and others) with the same values; without `dataset`, the most recently
  released copy is used and the others are listed in `other_datasets`.
- **frequency:** `auto` takes monthly observations when the series has them, else quarterly, else
  annual.
- **period:** `2025`, `2025-Q3`, `2025-07`, `last 5 years` or `YYYY-MM-DD:YYYY-MM-DD`; an
  observation is kept when its first day falls in the period. `latest_n` keeps the newest N.
- **Dates:** monthly `YYYY-MM`, quarterly `YYYY-Qn`, annual `YYYY`.

## Response Format

```json
{
  "cdid": "D7G7", "dataset": "MM23", "title": "CPI ANNUAL RATE 00: ALL ITEMS 2015=100",
  "unit": "%", "frequency": "monthly", "release_date": "2026-09-15", "next_release": "21 October 2026",
  "note_text": "Change over 12 months", "other_datasets": [],
  "uri": "/economy/inflationandpriceindices/timeseries/d7g7/mm23",
  "source": "Source: Office for National Statistics licensed under the Open Government Licence v3.0 (ons.gov.uk)",
  "observation_count": 2,
  "observations": [{"date": "2026-07", "value": 2.9}, {"date": "2026-08", "value": 3.1}]
}
```

## Calling the Tools

Every tool can be called over MCP (a `tools/call` request on `POST /mcp`) or over the REST API
(`POST /api/tools/execute`); see the [MCP Protocol Guide](../../protocol/MCP%20Protocol%20Guide.md)
and the [API Reference](../../protocol/API%20Reference.md).

```json
{"jsonrpc": "2.0", "id": 1, "method": "tools/call",
 "params": {"name": "ons_timeseries", "arguments": {"cdid": "MGSX", "latest_n": 12}}}
```

## Errors

| Situation | Result |
|---|---|
| A `cdid` that is not four characters | Argument error |
| No such series | Tool error pointing at `ons_search` |
| The CDID is not in the given dataset | Tool error naming the datasets that carry it |
| The shared request budget is used up | Tool error ("request budget ... used up") |
| ONS unreachable or another HTTP error | Tool error (`ONS ...`) |
