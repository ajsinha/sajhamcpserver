## Overview

The BEA tools (prefix `bea_`, folder `config/tools/bea/`) read the US Bureau of Economic Analysis:
the National Income and Product Accounts (GDP, income, spending), GDP by industry, the international
transactions accounts (balance of payments) and the regional accounts (state, county and metro
income and GDP). The `fred_*` tools re-publish many of the same series; these tools are the
first-hand source with BEA's own table structure. Implementation: `sajha/tools/impl/bea_tools.py`.
The live catalog in the app (Tools page, or `tools/list`) is authoritative.

## Data Source and Terms

- **API:** the BEA Data API, `https://apps.bea.gov/api/data` (`ResultFormat=JSON`).
- **Key:** a free 36-character UserID from `https://apps.bea.gov/API/signup/`, set in the environment
  variable `BEA_API_KEY`; the tool configs carry `"api_key": "${BEA_API_KEY:}"` and nothing goes in
  `config/application.yml`. BEA has no keyless tier: without the key every tool fails with "BEA API
  key not configured", and the live tool check reports `not_configured`.
- **Limits:** 100 requests, 100 MB and 30 errors a minute (HTTP 429 with `Retry-After`). Every
  request first takes a slot in one sliding window in the state store (`opendata:bea:requests`, 100 a
  minute), so all workers share the budget; results are cached for a day (`cache_ttl`).
- **Terms:** the [BEA API terms of service](https://apps.bea.gov/API/_pdf/bea_api_tos.pdf) require every
  application to display "This product uses the Bureau of Economic Analysis (BEA) Data API but is not
  endorsed or certified by BEA." Every result carries it in `source`; quote it with the data.
- **Outbound:** every request goes through the outbound fetch guard and the HTTP proxy
  (`sajha/core/outbound.py`).
- **Domain description:** `config/tools/bea/domain.txt`.
- **Test status:** no BEA key was available when these tools were built (release 8.15.0), so their test
  cases are skipped and have no cassettes, and the unit tests run on responses written from the BEA
  API user guide. Record the cassettes with a key:
  `python -m sajha.quality test --tool 'bea_*' --record` (after removing each case's `skip`).

## Datasets and Parameters

| Tool | BEA dataset | Parameters sent |
|---|---|---|
| `bea_datasets` | (`GETDATASETLIST`) | none |
| `bea_nipa_table` | `NIPA` | `TableName`, `Frequency` (`A`, `Q`, `M`), `Year` |
| `bea_gdp_by_industry` | `GDPbyIndustry` | `TableID`, `Frequency` (`A`, `Q`), `Year`, `Industry` |
| `bea_international_transactions` | `ITA` | `Indicator`, `AreaOrCountry`, `Frequency` (`A`, `QSA`, `QNSA`), `Year` |
| `bea_regional` | `Regional` | `TableName`, `LineCode`, `GeoFips`, `Year` |

- **Tables and codes:** NIPA tables such as `T10101` (percent change in real GDP), `T10105` (GDP),
  `T20600` (personal income, monthly); regional tables such as `SAINC1` (state personal income),
  `SAGDP1` and `SQGDP1` (GDP by state); ITA indicators such as `BalGds`, `BalServ`, `BalCurrAcct`.
  BEA's `GetParameterValues` method lists them all; `bea_datasets` lists the datasets.
- **years:** a list of years (default the last three, at most 20). Quarterly and monthly tables
  return every period of each year asked for.
- **Dates:** annual `YYYY`, quarterly `YYYY-Qn` (BEA's `2025Q1`, and GDP by industry's Roman quarters,
  are converted), monthly `YYYY-MM`.
- **Units:** `unit` is BEA's `CL_UNIT` and `unit_multiplier` its `UNIT_MULT` as a word (`millions`,
  `billions`); a value is in the unit times the multiplier.

## Response Format

```json
{
  "source": "Source: U.S. Bureau of Economic Analysis (BEA Data API, apps.bea.gov). This product uses the Bureau of Economic Analysis (BEA) Data API but is not endorsed or certified by BEA.",
  "dataset": "NIPA", "table": "T10101", "frequency": "quarterly", "years": [2025],
  "title": "Table 1.1.1. Percent Change From Preceding Period in Real Gross Domestic Product",
  "series_count": 1,
  "series": [{
    "key": "1.A191RL", "line": 1, "series_code": "A191RL", "description": "Gross domestic product",
    "metric": "Fisher Quantity Index", "unit": "Percent change, annual rate", "unit_multiplier": null,
    "observation_count": 2,
    "observations": [{"date": "2025-Q1", "value": -0.5}, {"date": "2025-Q2", "value": 3.8}]
  }],
  "notes": ["Table 1.1.1. ..."]
}
```

The values above are illustrative. Observations are oldest first; more series than `max_series`
gives `truncated: true` and a `note`.

## Calling the Tools

Every tool can be called over MCP (a `tools/call` request on `POST /mcp`) or over the REST API
(`POST /api/tools/execute`); see the [MCP Protocol Guide](../../protocol/MCP%20Protocol%20Guide.md)
and the [API Reference](../../protocol/API%20Reference.md).

```json
{"jsonrpc": "2.0", "id": 1, "method": "tools/call",
 "params": {"name": "bea_nipa_table", "arguments": {"table": "T10101", "frequency": "quarterly", "years": [2025]}}}
```

## Errors

| Situation | Result |
|---|---|
| `BEA_API_KEY` not set | Tool error "BEA API key not configured"; the live check reports `not_configured` |
| BEA refuses the UserID | Tool error naming `BEA_API_KEY` |
| Rate limit (HTTP 429 or BEA error 7), or the shared budget used up | Tool error saying so |
| An invalid table, year or industry | Tool error with BEA's error code and detail |
| BEA unreachable or refused by the outbound guard | Tool error (`BEA ...`) |
