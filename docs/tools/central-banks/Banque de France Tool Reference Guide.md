## Overview

The Banque de France tools (prefix `bdf_`) return French and euro area series: the ECB's key interest rates, euro reference exchange rates, France's 10-year government bond yield, French and euro area inflation, GDP, unemployment and M3. Implementation: `sajha/tools/impl/france_central_bank.py`. The live catalog in the app (Tools page, or `tools/list`) is authoritative.

Despite the prefix, the data comes from the **ECB Data Portal** (`data-api.ecb.europa.eu`), read through SAJHA's shared SDMX client (`sajha/tools/impl/sdmx_client.py`; [Tool Quality §12.3](../../architecture/Tool%20Quality.md#123-a-shared-sdmx-client)). Before 8.8.0 the tools called the ECB's retired host (`sdw-wsrest.ecb.europa.eu`) and failed. Each series key below was checked live, and each label reads its own series.

---

## Data Source and Keys

No API key. Fetches go through the outbound fetch guard and the HTTP proxy (`tools.outbound.*`, see the [Configuration Reference](../../getting-started/Configuration%20Reference.md)) and only to the ECB host.

### Common parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| `start_date` | string | Start period: `YYYY-MM-DD`, `YYYY-MM` or `YYYY` |
| `end_date` | string | End period, same forms |
| `recent_periods` | integer (1-100) | The last N observations of the series whatever its frequency (default 10); used only when neither date is given |

No argument is required; each tool's choice argument defaults to the first value below.

## Tool Reference

| Tool | Argument values (default first) | ECB series (flow / key) |
|------|--------------------------------|-------------------------|
| `bdf_get_oat_yield` | `bond_term`: `10y` | `IRS` / `M.FR.L.L40.CI.0000.EUR.N.Z`: France's long-term (10-year) government bond yield for convergence purposes, %, monthly. The ECB publishes no other French maturity, so 2y, 5y and 30y are not offered. |
| `bdf_get_ecb_policy_rate` | `rate_type`: `ecb_main_refi`, `ecb_deposit`, `ecb_marginal_lending` | `FM` / `B.U2.EUR.4F.KR.MRR_FR.LEV`, `...DFR.LEV`, `...MLFR.LEV`: %, one observation per change, so the last is the rate in force |
| `bdf_get_exchange_rate` | `currency_pair`: `eur_usd`, `eur_gbp`, `eur_jpy`, `eur_cny` | `EXR` / `D.<currency>.EUR.SP00.A`: units of the currency per euro, daily |
| `bdf_get_french_indicator` | `indicator`: `fr_cpi`, `fr_gdp`, `fr_unemployment` | `HICP` / `M.FR.N.000000.4D0.ANR` (HICP, annual rate of change, %); `MNA` / `Q.Y.FR.W2.S1.S1.B.B1GQ._Z._Z._Z.EUR.V.N` (GDP, current prices, EUR millions, quarterly); `LFSI` / `M.FR.S.UNEHRT.TOTAL0.15_74.T` (unemployment rate, 15-74, seasonally adjusted, %) |
| `bdf_get_eurozone_indicator` | `indicator`: `ez_cpi`, `ez_gdp`, `m3` | `HICP` / `M.U2.N.000000.4D0.ANR`; `MNA` / `Q.Y.I10.W2.S1.S1.B.B1GQ._Z._Z._Z.EUR.V.N` (euro area 21, EUR millions); `BSI` / `M.U2.Y.V.M30.X.I.U2.2300.Z01.A` (M3, annual growth rate, %) |

The ECB retired its `ICP` inflation dataflow in February 2026; inflation reads the `HICP` dataflow. For more ECB series (yield curve, euro STR, M1, M2) use the `ecb_` tools ([European Central Bank Tool Reference Guide](European%20Central%20Bank%20Tool%20Reference%20Guide.md)).

## Response Format

```json
{
  "flow": "HICP",
  "key": "M.FR.N.000000.4D0.ANR",
  "series_code": "HICP.M.FR.N.000000.4D0.ANR",
  "series_id": "fr_cpi",
  "label": "HICP Inflation rate - Total - Annual rate of change",
  "unit": "PCCH",
  "unit_multiplier": "0",
  "frequency": "Monthly",
  "source": "Source: ECB Data Portal (data-api.ecb.europa.eu)",
  "observation_count": 2,
  "observations": [{"date": "2026-08", "value": 2.6}, {"date": "2026-09", "value": 3.4}]
}
```

`label`, `unit` and `unit_multiplier` (a power of ten) are the ECB's own attributes. Observations are oldest first; a period with no data gives zero observations and a `note`. An unknown value or an ECB error is a tool error.

## Calling the Tools

Every tool can be called over MCP (a `tools/call` request on `POST /mcp`) or over the REST API (`POST /api/tools/execute`). Authenticate with an `X-API-Key: sja_...` header or an `Authorization: Bearer <token>` header. Sessions, protocol versions and headers are covered in the [MCP Protocol Guide](../../protocol/MCP%20Protocol%20Guide.md).

**MCP (`POST /mcp`)**

```json
{"jsonrpc": "2.0", "id": 1, "method": "tools/call",
 "params": {"name": "bdf_get_ecb_policy_rate", "arguments": {"rate_type": "ecb_main_refi", "recent_periods": 5}}}
```

**REST**

```bash
curl -X POST http://localhost:3002/api/tools/execute \
  -H "X-API-Key: sja_your_key" -H "Content-Type: application/json" \
  -d '{"tool": "bdf_get_ecb_policy_rate", "arguments": {"rate_type": "ecb_main_refi", "recent_periods": 5}}'
```

**Python client SDK**

```python
from sajhaclient import SajhaClient, SajhaConfig

client = SajhaClient(SajhaConfig(base_url="http://localhost:3002", api_key="sja_your_key"))
result = client.execute_tool("bdf_get_ecb_policy_rate", rate_type="ecb_main_refi", recent_periods=5)
```

## Troubleshooting

| Symptom | Cause / fix |
|---------|-------------|
| `Invalid <argument>: ...` | The value is outside the lists above (for example `bond_term` 30y). |
| `ECB Data Portal: ecb: HTTP ...` | The ECB rejected the request; check the date forms. |
| `ECB Data Portal: ecb: could not reach the SDMX service` | Network, proxy (`tools.outbound.proxy`) or a refused destination. |
| Zero observations and a `note` | No data in the requested period; widen the dates or use `recent_periods`. |
