## Overview

The People's Bank of China tools (prefix `pboc_`) return Chinese interest rates, the USD/CNY exchange rate, consumer prices and macro indicators. Implementation: `sajha/tools/impl/china_central_bank.py` on the shared base `sajha/tools/impl/central_bank_series.py`. The live catalog in the app (Tools page, or `tools/list`) is authoritative.

The tools do **not** call PBoC systems; the PBoC publishes no open API. Each series comes from one of two open sources, named in every result's `source`:

- the St. Louis Fed's [FRED](https://fred.stlouisfed.org/), which republishes OECD, IMF, BIS and World Bank series;
- the IMF's SDMX API (`api.imf.org`), read through SAJHA's shared SDMX client (`sajha/tools/impl/sdmx_client.py`).

Every series id was checked live. FRED carries no Chinese government bond yield, Loan Prime Rate, lending or deposit rate, or current money supply (its M0, M1 and M2 for China stopped in 2019), and the IMF has no Chinese monetary data either, so none of these is offered. `pboc_list_series` lists what is.

---

## Data Source and API Key

FRED-backed series need a free FRED API key ([fred.stlouisfed.org](https://fred.stlouisfed.org/docs/api/api_key.html)): `FRED_API_KEY`, config key `fred.api.key` (see the [Configuration Reference](../../getting-started/Configuration%20Reference.md)). Each `pboc_` config carries `"api_key": "${fred.api.key}"`, and the tools fall back to the environment variable (one lookup for every FRED-backed tool: `sajha/tools/impl/fred_key.py`). Without a key a FRED-backed call fails with "FRED API key not configured"; it never returns invented values. IMF-backed series (`cpi`, `cpi_inflation`, `gdp_growth`) and `pboc_list_series` need no key.

## Tool Reference

| Tool | Argument values (default first) | Series |
|------|--------------------------------|--------|
| `pboc_get_policy_rate` | `rate_type`: `discount_rate`, `interbank_3m` | FRED `INTDSRCNM193N` (PBoC discount rate, IMF series; changes rarely and is updated with a lag), `IR3TIB01CNM156N` (3-month interbank rate, OECD) |
| `pboc_get_exchange_rate` | `currency_pair`: `usd_cny` | FRED `DEXCHUS` (yuan per US dollar, daily) |
| `pboc_get_inflation` | `measure`: `cpi`, `cpi_inflation` | IMF CPI `CHN.CPI._T.IX.M` (index), `CHN.CPI._T.YOY_PCH_PA_PT.M` (% on a year earlier) |
| `pboc_get_economic_indicator` | `indicator`: `gdp_growth`, `gdp`, `exports`, `imports`, `trade_balance`, `house_price_index` | IMF WEO `CHN.NGDP_RPCH.A` (real growth, %; includes projections, and stops at the current year when no date is given); FRED `MKTGDPCNA646NWDB` (GDP, current USD, annual), `XTEXVA01CNM667S`, `XTIMVA01CNM667S`, `XTNTVA01CNM667S` (goods exports, imports and balance, USD, monthly, seasonally adjusted), `QCNN628BIS` (residential property prices, 2010=100, quarterly) |
| `pboc_list_series` | `category`: `all`, `rates`, `fx`, `prices`, `economy` | none: returns `{category, count, source, series: [{id, code, fred_code (FRED series only), source, label}]}` |

Removed in 8.8.0: `pboc_get_cgb_yield` (FRED has no Chinese government bond yield; the 3-month interbank rate it also served is `pboc_get_policy_rate` with `interbank_3m`) and `pboc_get_money_supply` (no current source). See the CHANGELOG.

## Response Format

```json
{
  "series_code": "CPI.CHN.CPI._T.YOY_PCH_PA_PT.M",
  "series_id": "cpi_inflation",
  "label": "CPI inflation, % change on a year earlier (IMF CPI), monthly",
  "source": "Source: IMF data portal (api.imf.org SDMX 2.1)",
  "observation_count": 3,
  "observations": [{"date": "2026-06", "value": 1.0}]
}
```

`series_code` is the FRED id, or the IMF dataflow and key. Observations are oldest first; missing values are dropped. An unsupported argument value or an upstream failure is a tool error.

## Calling the Tools

Every tool can be called over MCP (a `tools/call` request on `POST /mcp`) or over the REST API (`POST /api/tools/execute`). Authenticate with an `X-API-Key: sja_...` header or an `Authorization: Bearer <token>` header. Sessions, protocol versions and headers are covered in the [MCP Protocol Guide](../../protocol/MCP%20Protocol%20Guide.md).

**MCP (`POST /mcp`)**

```json
{"jsonrpc": "2.0", "id": 1, "method": "tools/call",
 "params": {"name": "pboc_get_inflation", "arguments": {"measure": "cpi_inflation", "recent_periods": 12}}}
```

**REST**

```bash
curl -X POST http://localhost:3002/api/tools/execute \
  -H "X-API-Key: sja_your_key" -H "Content-Type: application/json" \
  -d '{"tool": "pboc_get_inflation", "arguments": {"measure": "cpi_inflation", "recent_periods": 12}}'
```

**Python client SDK**

```python
from sajhaclient import SajhaClient, SajhaConfig

client = SajhaClient(SajhaConfig(base_url="http://localhost:3002", api_key="sja_your_key"))
result = client.execute_tool("pboc_get_inflation", measure="cpi_inflation", recent_periods=12)
```

## Troubleshooting

| Symptom | Cause / fix |
|---------|-------------|
| "FRED API key not configured" | Set `FRED_API_KEY` (see [Data Source and API Key](#data-source-and-api-key)). |
| `Unsupported ...` error | The argument value is outside the lists above. |
| `FRED has no series ...` / `IMF data portal: ...` | The upstream rejected the request; check dates are `YYYY-MM-DD`. Chinese series lag official releases. |
| Empty `observations` | No data in the requested range; widen the dates or use `recent_periods`. |

Data notes: the series are monthly, quarterly or annual and lag official releases. Times are dates only (no time zone).
